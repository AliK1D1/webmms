# webMMS

Site de la compagnie webMMS : sites web et solutions pour les entreprises de la Rive-Sud.

Site statique (HTML, CSS, JS), sans dépendance ni étape de construction.

## Structure

- `index.html` : la page
- `css/style.css` : le style
- `js/main.js` : menu cellulaire, apparitions au défilement, métiers qui s'écrivent
- `img/` : favicon et captures des réalisations
- `font/` : Montserrat et Open Sans, hébergées sur place (licence OFL, voir `font/licences`)

## Mise en ligne sur Render

New → Static Site → ce dépôt.

- Build Command : (vide)
- Publish Directory : `.`

## Aperçu local

Ouvrir `index.html` dans un navigateur.
